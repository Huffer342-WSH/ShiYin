# 时音 · ShiYin

时音是 Kotlin + Jetpack Compose 编写的 Android 本地音乐播放器，支持播放列表、目录管理和定时闹钟播放。

## 功能

- 播放本机音频，支持搜索、临时队列、随机/循环播放与睡眠定时。
- 保存播放列表，通过系统目录授权收录文件夹及其子目录中的音乐。
- 按指定日期、星期或中国大陆工作日播放闹钟，支持淡入、时长上限、倒计时与全屏响铃页（需系统及厂商权限）。
- 支持预设配色、自定义主色、深浅色与系统动态配色。

最低支持 Android 7.0（API 24），主要验收目标为 Android 15 真机。当前不支持网络流媒体和 SMB；中国大陆工作日日历需要联网下载，缓存后可离线使用。详细行为与限制见 [项目说明](docs/项目说明.md)。

## 下载与使用

在 [GitHub Releases](https://github.com/Huffer342-WSH/ShiYin/releases) 选择对应版本。日常安装选 `ShiYin-版本-release.apk`，调试选 `ShiYin-版本-debug.apk`。预发布标为 Pre-release。两种 APK 共用包名，签名不同；从旧测试包切换时请先保存重要数据。

首次设置、歌词导入和锁屏响铃操作见[使用手册](docs/使用手册.md)。

vivo Android 15 真机上已有一次正式播放器关闭任务卡片后锁屏定时出声的记录。重复触发、长时间待机和耳机输出仍待验证。[查看真机样本](docs/工作记录/2026-11-17-正式播放器后台运行接入.md)
