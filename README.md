# 时音 · ShiYin

时音是 Kotlin + Jetpack Compose 编写的 Android 本地音乐播放器，支持播放列表、目录管理和定时闹钟播放。

## 功能

- 播放本机音频，支持搜索、临时队列、随机/循环播放与睡眠定时。
- 保存播放列表，通过系统目录授权收录文件夹及其子目录中的音乐。
- 按指定日期、星期或中国大陆工作日播放闹钟，支持淡入、时长上限、倒计时与全屏响铃页（需系统及厂商权限）。
- 支持预设配色、自定义主色、深浅色与系统动态配色。

最低支持 Android 7.0（API 24），主要验收目标为 Android 15 真机。当前不支持网络流媒体和 SMB；中国大陆工作日日历需要联网下载，缓存后可离线使用。详细行为与限制见 [项目说明](docs/项目说明.md)。

## 下载与使用

从 [GitHub Releases](https://github.com/Huffer342-WSH/ShiYin/releases) 下载测试 APK。现有发布流程使用临时调试签名，不能保证跨版本覆盖安装；不要为解决签名冲突直接卸载，否则会丢失应用设置、播放列表和闹钟。

首次打开后授权读取音频，或在“目录”中选择本地文件夹。使用闹钟前检查“闹钟和提醒”与通知权限，并先试听。设置好闹钟后，在底部 tab 栏向上滑动进入后台，由 App 在等待服务就绪后主动关闭卡片；这不等同于系统上划清理。锁屏、Doze、厂商后台限制和耳机实际输出仍需 Android 15 真机验证，已有模拟器结果见 [验证记录](docs/验证记录.md)。
