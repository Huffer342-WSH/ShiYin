# 项目说明

时音（ShiYin）是 Kotlin + Jetpack Compose 的本地音频播放器，附带闹钟播放功能。歌曲、播放列表、目录和闹钟是四个主栏目，可点击导航或左右滑动切换；设置从更多菜单进入。页面不展示产品名、宣传卡片或常驻帮助段落。

## 播放器

- 歌曲可搜索，支持播放/暂停、进度、上一首/下一首、随机、单曲/列表循环。
- 临时播放队列支持追加、下一首播放、移除、上移/下移和保存为播放列表；追加歌曲不会暂停当前播放。
- 播放列表独立保存，支持新建、重命名、删除、多选管理歌曲、排序和播放。添加时按 URI 去重；删除列表或移除歌曲不会删除音频文件。
- 迷你播放器可打开完整播放页。完整播放页的更多菜单提供睡眠定时、保存播放列表、创建闹钟和停止播放。
- 睡眠定时为 1–1440 分钟，可取消，显示剩余时间；换歌继续计时，到点停止当前播放。它不退出应用、不删除后续闹钟。新闹钟开始会取消已有睡眠定时。
- 手动播放使用媒体音量；通知栏、锁屏及耳机媒体按键由 Media3 会话提供。

## 音乐目录

未配置目录时，授权后读取系统 MediaStore 音频库。配置至少一个指定目录后，歌曲页仅收录这些目录及子目录中的音频。

目录通过 Android 系统选择器授权，只支持本机或存储卡的 ExternalStorage DocumentsProvider，不申请“所有文件访问”权限。授权保存后，重新打开应用或设备重启后仍可访问；授权被撤销、目录不可用或文件无法读取时显示错误。

目录详情提供两种视图：“浏览”逐层显示子目录和本层音频；“全部音频”递归汇总所选根目录的歌曲，是实时集合而非保存的播放列表。长按音频进入多选，可逐项勾选、全选当前视图或长按滑动连续选择，滑到列表边缘自动滚动；选中后可加入已有或新建的播放列表，不复制文件。返回先退出多选，再返回上级目录。

支持 M4A 容器中的 AAC 音频；测试素材位于 `test-fixtures/audio/dawn-aac.m4a`。其他编码、损坏或受保护的文件仍可能无法解码，不能仅凭后缀保证可播放。

前台使用期间监听目录/媒体变更通知，并约每 15 秒补扫；再次进入前台立即补扫。退出前台后不为扫描常驻服务。扫描、目录遍历和元数据提取在 IO 线程执行，未改变的文件复用元数据缓存。

停止监控只取消收录，保留系统读取授权，以便已有播放列表、队列和闹钟继续访问原文件。授权可在系统中撤销。被删除或移动的文件不会从保存的播放列表中静默移除；播放时会明确报错。

当前没有 SMB、音乐平台、网络流媒体或 M3U 导入/导出。

## 闹钟

新建闹钟时选择歌曲、时间、日期/星期/中国大陆工作日规则、淡入时长和单次时长上限。

- 新建默认淡入 15 秒；可关闭或设为 0–300 秒，必须小于单次上限。旧任务缺少淡入字段时按 0 秒读取，原有行为保持不变。
- 单次上限为 1–1440 分钟，默认 30 分钟。单曲循环到上限后停止；上限按经过时间计算，包含准备和暂停。
- 淡入从音频真正开始播放时累计，暂停期间不推进；只改变播放器增益，不修改系统闹钟音量。试听采用相同淡入速度，最多 30 秒，较长淡入可能不会在试听中完成。
- 新闹钟替换当前播放，不自动恢复原队列。定时/试听优先已连接的有线/USB 耳机，其次蓝牙 A2DP/BLE；实际路由需先试听。耳机断开或音频焦点丢失时暂停。
- 任务使用手机当前时区。重复任务逐次注册下一次闹钟，支持精确闹钟权限检查、重启首次解锁后及时间/时区变更后的恢复。
- 系统正常投递最多容忍 2 分钟延迟，超过后不补播。等待期间不常驻，播放期间使用前台媒体服务。
- 返回桌面或划掉页面不主动取消任务。系统“强行停止”会使闹钟失效，重新打开后恢复未来任务；关机期间不能播放。
- 不支持正在播放时的进程崩溃续播或重启后首次解锁前播放；未来系统闹钟独立于当前播放进程。

中国大陆工作日日历来自 [holiday-cn](https://github.com/NateScarlet/holiday-cn)，联网下载并校验年度 JSON，包含放假和补班覆盖项。下载成功后离线使用，更新失败保留旧数据。缺少目标年份时暂停该规则的下一次调度并提示，不猜测工作日。其他地区待有可靠的补班数据后再扩展。

## 主题与保存

主题支持森林、海蓝、暮紫、暖橙及自定义主色（`#RRGGBB`），另可选择系统/浅色/深色模式。自定义主色生成配套色调，并调整主色明度保证文字对比度。Android 12 以上可选择壁纸动态配色。

任务、播放列表、监控目录、日历和主题保存在应用私有 `shiyin.xml`。播放列表和目录使用独立版本键，任务 JSON 新字段兼容旧记录。本机音频 URI 不能跨设备复用，因此该文件不参加云备份和设备迁移。清除应用数据或卸载会丢失这些设置。
