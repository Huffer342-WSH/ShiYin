# 开发环境搭建

从项目根目录执行下面的命令。Android Studio 用于管理 SDK、模拟器与 IDE 调试，项目自带 Gradle Wrapper 负责构建；Android CLI 和 skills 用于辅助 Agent 开发，不是 APK 的运行依赖。

## 使用项目构建容器

Linux x86_64 已安装 Docker 时，可直接运行 `bash docker/android/run.sh`，默认构建 Debug APK、执行 JVM 单测和 Lint，无需在宿主机安装 JDK/SDK。源码只读挂载，产物和缓存位于 `.container`，不会覆盖 IDE 的 SDK 配置与构建目录。完整参数、产物路径和签名注意事项见[容器说明](../docker/android/README.md)。模拟器仍由宿主机管理。

## JDK 与 Android SDK

1. 安装 Android Studio 和 JDK 25，在 IDE 的 Gradle JDK 设置中选择兼容的 JDK。项目的 Daemon JVM 要求见 [gradle-daemon-jvm.properties](../gradle/gradle-daemon-jvm.properties)；源码的 Java 11 兼容级别不是 Gradle 运行时版本。
2. 在 SDK Manager 安装 Android SDK Platform 37.0、Build Tools 37.0.0 和 Platform Tools。要运行模拟器时另装 Emulator 与所需系统镜像；主要验收设备仍为 Android 15 真机。
3. 用 Android Studio 打开项目并生成本机 `local.properties`，确认 `sdk.dir` 指向本机 SDK；该文件不提交。终端需要能找到 `adb` 和 JDK，`JAVA_HOME` 指向 JDK 25。

已有 SDK command-line tools 时，也可用 `sdkmanager` 安装与 CI 相同的平台组件：

```sh
sdkmanager "platforms;android-37.0" "build-tools;37.0.0" "platform-tools"
java -version
adb version
```

SDK 许可按安装器提示接受。平台版本以 [依赖目录](../gradle/libs.versions.toml)、[模块配置](../app/build.gradle.kts) 和 [CI 工作流](../.github/workflows/android.yml) 为准。

## Android CLI 与项目 skills

本机已安装 CLI 时先执行 `android --version`。Linux x86-64 新环境可使用 Google 提供的安装脚本：

```sh
curl -fsSL https://dl.google.com/android/cli/latest/linux_x86_64/install.sh | bash
```

安装后按输出提示配置 PATH，重新打开终端并检查：

```sh
android --version
android skills add --help
```

已安装 `android-cli` 技能时，可在本机 `.agents/skills/android-cli/SKILL.md` 的 Installation 一节查看其他平台的命令。

在 **ShiYin 项目根目录** 安装所需技能；`--project=.` 指定当前项目，默认面向 CLI 检测到的 Agent。只需安装缺失项，已有完整副本时可跳过：

```sh
android skills add adaptive --project=.
android skills add android-cli --project=.
android skills add android-intent-security --project=.
android skills add android-permissions-security --project=.
android skills add android-profiler --project=.
android skills add anr-audit-and-fix --project=.
android skills add edge-to-edge --project=.
android skills add jetpack-compose-performance --project=.
android skills add navigation-event --project=.
android skills add r8-analyzer --project=.
android skills add testing-setup --project=.
```

这些技能覆盖自适应布局、系统栏、返回手势、权限与 Intent 安全、性能、ANR、R8 和测试。不要用 `--all` 恢复 AI、相机、支付、其他设备平台等当前项目不需要的技能。

`mobile-android-design` 是另一个来源的项目内技能，不在 Android CLI 技能目录中；它随项目保留在 `.agents/skills/mobile-android-design`，无需执行 `android skills add mobile-android-design`。来源与许可证见 [SOURCE.md](../.agents/skills/mobile-android-design/SOURCE.md)。

安装后确认项目 `.agents/skills/<技能名>/SKILL.md` 存在；如需只安装给某个 Agent，可先查 `android skills add --help` 中的 `--agent` 参数。技能作为按任务读取的参考，依赖版本和项目行为仍以本项目配置与说明为准。

## 首次构建

使用项目自带 `./gradlew`，不安装全局 Gradle。Wrapper 版本见 [配置文件](../gradle/wrapper/gradle-wrapper.properties)。完成前面的 JDK 和 SDK 配置后执行：

```sh
./gradlew :app:assembleDebug
```

原开发机的 Android Studio 位于 `/home/wushenhui/.local/opt/android-studio`，也可使用其 JBR：

```sh
JAVA_HOME=/home/wushenhui/.local/opt/android-studio/jbr ./gradlew :app:assembleDebug
```

成功条件为 `BUILD SUCCESSFUL`，且生成 `app/build/outputs/apk/debug/app-debug.apk`。首次构建需要下载 Gradle 和依赖；下载失败应先检查报错与网络，不直接更换依赖版本或关闭校验。

其他机器将 `JAVA_HOME` 换为匹配项目要求的 JDK；终端与 IDE 的 JDK 设置需核对一致。使用 IDE 时可直接选择设备后点击 Run。

环境就绪后，按 [开发指南](开发指南.md#测试与设备运行) 执行测试和安装；发布 APK 见 [构建与发布](构建与发布.md)。
