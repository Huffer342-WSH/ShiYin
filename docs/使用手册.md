# 时音使用手册

首次打开时，时音会请求音乐和通知权限，随后显示使用手册。拒绝授权后，可在设置中重新授权。首次升级到带手册的版本也会显示一次，以后可从“更多 → 帮助”或“设置 → 使用说明”打开。

使用闹钟时，按需要打开对应设置：

- 定时触发：进入“设置 → 闹钟和提醒”，允许时音设置精确闹钟。
- 锁屏显示响铃页：进入“设置 → 全屏闹钟”。vivo 设备还需检查系统的“锁屏显示”权限。
- 厂商后台限制：进入“设置 → 权限与后台”，查看自启动与后台锁定说明。

## 收录本地音乐

在“目录”中选择音乐文件夹，或授权读取系统音乐库。目录包含子目录，可逐层浏览、多选并添加到播放列表。先试听，确认文件可读取和音量合适。

## 播放页与歌词

点击迷你播放器进入完整播放页，左右滑动切换封面、波形和歌词。波形由本地音频分析生成，表示随时间变化的相对振幅；分析失败不影响播放。进度条拖动时显示目标时间，松手后跳转。

歌词页可导入 UTF-8 LRC 文件（最多 256K 字符），保存后随播放时间显示当前句。当前没有在线歌词下载或语音转字幕。

## 时刻闹钟与倒计时

- 时刻闹钟：在闹钟栏目添加，选择歌曲、日期/重复规则、淡入与单次播放上限。
- 倒计时：从更多菜单打开“倒计时闹钟”，输入 1～86400 秒，选择本地歌曲和播放上限，点击“开始计时”。默认 20 秒等待、1 分钟播放，可自行调整。
- 倒计时出现在闹钟列表，以剩余秒数和总时长为主，响铃时刻为辅助信息。可以关闭或删除；需要改变时长或歌曲时，删除后重新创建。
- 睡眠定时是“到点停止当前播放”，倒计时闹钟是“到点开始播放”，两者不同。

当前倒计时按结束时刻持久保存；修改系统日期/时间会影响剩余等待。点击卡片或再次启用会按保存的总时长重新计时；到期不会自行循环。旧记录未保存总时长，需重新设置一次。

## 后台等待与最近任务卡片

允许通知与“闹钟和提醒”后，只要保存或启用了未来的定时任务，App 会自动启动后台等待服务（`AlarmStandbyService`）。

在 vivo OriginOS 5（Android 15）真机上的实测结论与建议：

1. **推荐的系统权限**：在“应用信息 → 查看所有权限”中开启“自启动”“关联启动”“锁屏显示”（声明导出 `BOOT_COMPLETED` 广播接收器后，vivo 权限页会显示“自启动”开关）；在“电池 → 后台耗电管理”中选择“允许后台高耗电”。
2. **为什么不能在系统最近任务里手动上划卡片**：
   - 在 vivo OriginOS 5 上，只要用户在系统最近任务（`com.vivo.recents`）中手动将非白名单第三方应用的卡片向上划掉（**无论卡片是否加锁、无论是否开启自启动/后台高耗电、无论是否运行前台服务或播放静音音频**），系统都会直接调用 `forceStopPackage`，将应用置为 `stopped=true, vStopped=true`，立即 `SIGKILL` 进程并清空该包注册的所有 `AlarmManager.setAlarmClock` 闹钟。
   - **卡片加锁的真正作用**：给最近任务卡片加锁（显示锁头图标）只能防止点击底部“清除全部（×）”按钮时被一键清理；**不能**防止用户手动把这张加锁卡片向上划掉。
3. **三种后台运行方式（推荐可选守护包）**：
   - **方式一（推荐 · 安装可选「时音闹钟守护」防划卡失效）**：在首次进入「闹钟」栏目弹窗、或通过「设置 → 闹钟守护包」「设置 → 权限与后台」安装配套守护包（无桌面图标、无常驻最近任务卡片）。安装后请完成以下两步授权：
     1. 点击「前往守护设置（必开精确闹钟）」，为「时音闹钟守护」允许精确闹钟；如需在卸载时音后收到一键卸载提醒，可同时开启守护通知权限。
     2. 点击「打开守护系统应用信息」，为「时音闹钟守护」开启「自启动」「关联启动」并在「电池 → 后台耗电管理」设为「允许后台高耗电」（在 vivo OriginOS 5 上若保持默认“智能控制后台耗电”，守护闹钟仍会被延迟或拦截）。完成后点击「完成设置并隐藏卡片」。
     完成上述设置后，即使主应用未加锁且被手动上划卡片或点击「清除全部（×）」，到点仍可准时唤醒时音响铃。可在「设置 → 闹钟守护包」随时卸载；卸载时音主应用后，守护包会自动清空预约并（在已授通知权限时）弹出卸载提醒通知。
   - **方式二（不安装守护包 · 保留卡片 + 卡片加锁）**：在系统最近任务中给时音卡片**加锁**，日常直接按 Home 键或手势退回桌面；清理其它后台时点底部的“清除全部（×）”按钮（已加锁的时音卡片会被跳过，闹钟正常触发），但**不要手动把时音卡片往上划掉**。
   - **方式三（不安装守护包 · 应用内上滑收起）**：如果不想在最近任务里看到时音卡片，请在时音底部 tab 栏向上滑动至少 48dp 后松手，由 App 确认等待服务就绪后主动调用 `finishAndRemoveTask()` 收起卡片——这种方式不会触发系统的 `forceStopPackage`，闹钟可正常触发。

可从等待通知重新打开 App。只要仍有未来任务，开机解锁、覆盖升级或打开应用时都会自动同步恢复等待服务；全部任务关闭或触发结束后自动停止等待服务。若未安装守护包且在系统最近任务中被手动上划或点“强行停止”进入 `vStopped=true`，必须手动重新打开一次应用才能恢复。长时间待机、Doze 和不同 ROM 仍建议先在自己的手机上实测验证。

## 全屏响铃

在“设置 → 全屏闹钟”中允许系统全屏通知。vivo 还可能需要在“应用信息 → 查看所有权限”中开启“锁屏显示”；本次真机显示成功使用了这一权限，没有开启后台弹出界面。

锁屏时系统可以显示带动画的响铃页；解锁使用手机时，系统可能只显示横幅。通知和厂商权限不足时，不能保证页面自动弹出。

- “收起，继续播放”：只关闭响铃页，音频由播放服务继续管理。
- “停止本次闹钟”：停止当前响铃，不删除之后的重复计划。
- 到达播放上限、播放失败或切换手动播放时，本轮响铃页和通知会清理。

闹钟与倒计时使用闹钟音频属性；蓝牙音量和实际输出需单独验证。测试或调整设置时，避免同时修改多个音量和后台权限。
