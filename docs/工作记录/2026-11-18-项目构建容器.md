# 项目自带 Android 构建容器

## 范围

新增 docker/android 的 Dockerfile、入口脚本与说明。固定 Temurin JDK 25 基础镜像 digest、Android CLI 下载版本和校验值，安装 SDK 37.0 / Build Tools 37.0.0，使用项目 Gradle Wrapper。仅支持 Linux amd64，不安装模拟器和 NDK。

运行入口：`bash docker/android/run.sh`。源码只读挂载，按宿主 UID/GID 在 `.container/workspace` 副本构建，Gradle 缓存和调试签名保存在 `.container`。不修改 IDE local.properties 或 app/build；文件锁阻止同一副本并发构建。

不改变现有 GitHub Workflow，不发布镜像或新版本，不提交代码。隔离验证发现 AGP 默认请求 Build Tools 36.0.0，已在 app/build.gradle.kts 显式固定为 37.0.0，与现有 CI 安装命令和容器一致，避免依赖宿主机预装旧版本。
