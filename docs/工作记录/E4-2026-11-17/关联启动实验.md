# 自启动入口与关联启动对照

2026-11-17，vivo V2463A / Android 15。目标为无最近任务卡片且锁屏仍能定时播放。本轮未找到满足该目标的方案。

## 实际操作与结果

1. 核对实验包 targetSdk=34、已解锁；后台耗电页面仍勾选“允许后台高耗电”。
2. 应用权限页仅有“关联启动”，初始关闭，无自启动开关。
3. 从系统已声明的 com.iqoo.secure.BGSTARTUPMANAGER 入口进入自启动列表，全部 152 个应用；搜索“闹钟实验”和“闹钟”均无结果。未改其他应用开关。
4. 为排查入口筛选条件，在独立实验包新增 RECEIVE_BOOT_COMPLETED 和私有 BootProbeReceiver。接收器只记录 boot_received，不启动服务、不恢复预约、不保活。构建、SDK 34 单元测试与 Lint 通过；覆盖安装 Success。系统已识别接收器及权限，但刷新列表、启动实验应用后，仍找不到自启动条目。不能认定补接收器已经解决授权入口问题。
5. 在应用权限页打开“关联启动”，确认系统提示中的“允许”，读回子开关 CHECKED。其他权限保持原样；这是关联启动测试，不是自启动测试。
6. 预约 15:08:53.631，运行标识 ac5b135c-daa6-42db-b956-c53fe962f4dd。只上划实验包卡片，再熄屏。
7. 上划瞬间读到 stopped=false、预约尚在；动画结束后再次查询为 stopped=true、vStopped=true，实验 Activity 已不在最近任务，预约消失，keyguard showing=true。
8. 15:09:15 查询没有播放服务；导出私有日志，无本轮 service_delivery / focus / play_started。

结果：本轮组合“SDK 34＋允许后台高耗电＋关联启动”仍未实现划卡后锁屏触发。新增接收器与关联启动同时区别于旧 APK，本轮不是严格同 APK 的开关 A/B，但失败现象仍是包被停用和预约消失。
