## 如何维护

- 每项工作用日期和主题命名，写明目标、已知事实、待确认假设、下一步和完成条件。
- 实验计划与实际结果分开。计划中的“待执行”只有在留下设备、测试包、操作和证据后才能改为“通过”或“失败”。
- 每次继续工作先看任务状态；结束时更新实际完成项、失败原因与下一步，不把聊天中的猜测写成结论。
- 完成后将任务状态改为“已完成”或“已终止”，保留原路径；有价值的结论同步到所属说明或验证记录。
- 未完成实验不算发布验证。当前文档不授权恢复已回滚代码、改手机权限或发布 APK；执行时仍按当次任务范围处理。
