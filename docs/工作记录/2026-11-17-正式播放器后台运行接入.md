# 正式播放器后台运行接入

用户要求先保存下一步计划，再恢复正式播放器并接入 App 主动关闭卡片。后续方案仅允许单 App、普通权限；同包双进程仍为待实验，不采用独立或外部特权守护。

## 已完成代码

按用户确认恢复仓库 d7a50fc 中的播放器、页面、主题、依赖、配套测试与 UI 指引。保留当前工作记录、实验工程、开发环境/发布文档及其他用户文件。包名 com.Huffer342.shiyin、minSdk 24、targetSdk 37 不变，继续读写原 shiyin 数据，不清空手机数据。

- MainActivity 新增更多菜单“后台运行”，歌曲首页返回使用同一路径。singleTask 避免重复创建同类任务；等待服务回复成功后调用 finishAndRemoveTask。
- AlarmStandbyService 私有、不随任务结束，Android 14+ 使用 systemExempted 类型并核查精确闹钟授权。等待有持续通知，不用静音音频、永久唤醒锁或忙循环。
- 有启用但未注册的闹钟、通知/精确闹钟权限不足、服务启动失败或超时，保留页面并提示。没有启用任务则不新增等待服务。
- 任务取消/禁用后更新等待状态，全部失效后退出。最后一个单次闹钟消费期间保留前台状态，实际播放或准备失败后再释放等待状态。
- PlaybackService 显式注册 MediaSession，增加准备阶段 15 秒超时及短时唤醒锁；手动播放、结束和销毁都清理准备状态。
- 帮助与项目说明同步说明“App 自己退出”和“系统手动上划”的区别。没有将实验 20 秒倒计时带入正式闹钟规则。

从仓库恢复的版本不包含此前未提交的 AlarmActivity / AlarmPresentation 全屏页和 AlarmDiagnostics 对话框，本次未把它们伪称为已恢复功能。
