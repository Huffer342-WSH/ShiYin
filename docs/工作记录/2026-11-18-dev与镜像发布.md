# dev 分支、GHCR 与独立发布流程

## 范围

- 新建 dev，日常推送不执行 App CI；PR → main、push main 执行统一检查。交付后继续停留在 dev。
- 忽略本机 IDE、缓存、构建产物、密钥和下载的辅助 skills，保留已维护的 mobile-android-design。
- 删除加法和包名两个模板测试，保留 38 项业务单测及设备回归。
- Build Image 发布 GHCR；CI 固定 image.txt 中的 digest，使用镜像执行 Lint/单测/构建。模拟器继续使用宿主 KVM。
- Release 按 tag 提交精确查询成功 main CI，等待进行中的 CI；无产物/过期时重新检查，已失败 CI 阻止发布。校验 APK 摘要、commit、versionName 和镜像 digest，不跨提交复用。
- 本次测试版本计划 v1.1.2 / versionCode 4，仍为临时调试签名。
