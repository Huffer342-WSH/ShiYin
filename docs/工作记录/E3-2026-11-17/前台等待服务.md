# 前台等待服务与无卡片实验

2026-11-17，vivo V2463A / Android 15。用户目标：优先实现无最近任务卡片且锁屏定时播放；实在不可行才接受后台卡片锁定。

## 后续配置调整

用户要求将实验等待改为 20 秒，已同步两个预约按钮、实际触发时间与实验 README；播放上限仍为 60 秒。SDK 34/37 构建与现有单元测试通过，SDK 34 已覆盖安装到 vivo（Success）。本次未预约或播放；下文历史三分钟实验结果不改写为 20 秒结果。

## 本轮改动

仅修改独立实验工程，正式 app 未改。新增私有 WaitingService，使用 systemExempted 类型，在页面可见时由用户点击启动，并显示持续通知。实际资格来自已授予的精确闹钟权限，见 [Android 服务类型说明](https://developer.android.com/develop/background-work/services/fgs/service-types#system-exempted)，不是获得 QQ 厂商白名单。

等待不播放声音、不持有唤醒锁、不忙循环。仍由 AlarmManager 预约播放服务，到点媒体服务前台化后停止等待服务。取消时停止两种服务；等待服务另设 Handler 5 分钟超时（该计时不保证设备深睡时的墙钟截止）。START_NOT_STICKY，不掩盖系统清理后自动重启与否。

预约统一改为点击后 3 分钟。增加 WaitingWindowTest，验证旧标识、过期及超出实验窗口不能保持等待服务。构建、SDK 34 与 SDK 37 单元测试及 Lint 均通过。设备结果按下文的 APK 和运行标识分别记录。
