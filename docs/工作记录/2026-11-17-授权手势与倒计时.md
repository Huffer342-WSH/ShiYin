# 系统授权、上滑后台与倒计时重启

## 实现

- 首次主动调用 RequestMultiplePermissions 申请尚未授权的音乐与通知，系统显示授权框；持久记录已申请，拒绝不自动重试。权限与后台入口移至设置。精确闹钟、全屏和厂商自启动仍需系统设置授权，不能伪装成普通权限弹窗。
- 删除顶部和菜单的后台运行按钮。手机底部 tab 栏向上拖动超过 48dp 后松手进入后台，普通点击仍切换栏目；提供无障碍自定义操作。无 tab 栏的播放/编辑页面需先返回主栏目；歌曲首页返回仍可进入后台。
- 新倒计时保存 countdownSeconds，点击卡片或重新开启开关会从总时长重启，同一任务 ID 替换旧预约；不是到期自动无限循环。卡片以剩余秒数和总时长为主，响铃时刻为辅。
- 旧倒计时总时长缺失时不猜测，提示重新设置。墙钟修改仍会影响剩余时间。

## 验证

assembleDebug、testDebugUnitTest、lintDebug、assembleDebugAndroidTest 通过。CountdownTest 增加重启后截止时间、任务 ID 与总时长保持、旧数据缺失拒绝重启；导航测试适配新手势区域。设备测试 APK 已编译，未运行 instrumentation。20:20 已覆盖安装 vivo。页面顶部按钮已移除，旧倒计时卡片显示剩余 0 秒和总时长未记录；底部导航上滑后前台回到 Launcher。本轮未记录等待服务/预约证据，因此不算后台响铃验证；没有实测新倒计时重复触发或新安装授权框。不清空用户数据或撤销现有权限来模拟新安装。
