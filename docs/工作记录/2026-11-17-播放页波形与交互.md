# 播放页波形与交互优化

## 修改

- 底部导航上滑改为整页跟手上移、缩小与圆角，露出全屏后台状态；不足阈值回弹，达到阈值后完成 320ms 整页收起动画再调用后台流程。准备服务期间保留状态页，失败恢复原页面。模拟器专项测试 OK (1 test)，检查不足阈值不退出、动画进度达到 1 后才触发退出；本次构建、单测与 Lint 通过，已覆盖安装模拟器，未验证真机。
- 闹钟保存不再切换全局 busy，避免所有开关短暂禁用及顶部加载条闪现。倒计时重新启用或截止时间改变时立即重置计时基准；关闭时停止计时刷新。
- 非默认主题的背景、surface、各层容器与轮廓一起按主色调整，保留深浅模式的正文对比度；动态壁纸色仍以系统生成配色为准。
- 播放进度条改为圆形拖动点、细轨道与强调色时间；拖动中显示预览位置，松手才提交 seek。
- 完整播放页支持左右滑动切换封面、真实音频波形、歌词。波形通过 MediaExtractor/MediaCodec 解码 PCM16/float，固定 240 个峰值区间，纵向按本曲峰值归一化，不是分贝计或频谱图。
- 波形按需分析；页面离开、切歌或生命周期停止时取消，最长分析 60 秒，失败只提示，不影响播放。当前不持久缓存，重新打开播放页可能重新分析。
- 歌词支持手动导入 UTF-8 LRC，单文件最多 256K 字符，按歌曲 URI 保存文本；显示当前句及前后句，随播放位置更新。不自动识别语音，不下载在线歌词，未实现 SRT/内嵌字幕。

## 验证

API 37 模拟器 Medium_Phone_API_37.0 / emulator-5554，软件渲染，未清空数据。正式 App 和测试 APK 均覆盖安装。

- assembleDebug、testDebugUnitTest、lintDebug、assembleDebugAndroidTest 通过。
- PlaybackVisualTest 实际运行 OK (6 tests)，约 11 秒：上滑阈值/动画回调、拖动尚未松手时更新时间、主题 surface 变化、倒计时关闭与重启时间、保存的歌词随位置更新、真实解码静音/有声两个区段。
- LyricsTest 覆盖多时间标签、分数秒、offset、无效秒数及纯文本不冒充带时间歌词。
- 完整 App 播放“晨光 · AAC 示例”，波形页显示真实淡入、振幅起伏与淡出；已目视检查播放进度条布局。
- 未执行全量既有 instrumentation；未做帧耗时分析，不能据此宣称无掉帧。倒计时回归测试验证显示状态，未量化整页闪烁。
- 本轮没有操作 vivo 真机，模拟器结果不代表后台/锁屏可靠性。文件选择器导入全流程、其他编码歌词、超长音频及所有解码器仍待补充验证。
