# ShiYin v1.1.1

本地音乐播放器与闹钟体验更新，APK versionName 1.1.1 / versionCode 3。v1.1.0 因 CI runner 磁盘不足未发布，本版修复环境准备并保留全部测试门禁。

- 后台等待、App 主动关闭卡片、开机解锁后尝试恢复等待，以及系统权限和厂商后台设置引导。
- 全屏响铃与停止控制；倒计时支持按原时长重新开始。
- 底部 tab 上滑触发整页收起动画，未达到阈值时回弹。
- 播放页横滑切换封面、真实音频波形和本地 LRC 歌词；进度条拖动时同步显示目标时间。
- 修复倒计时切换闪烁、主题背景未跟随配色的问题。
- GitHub CI 拆分 build/test/release，测试和发布复用同一次 build APK，校验 SHA-256；PR/main 不发布，版本 tag 通过全部检查后发布。

验证包括本地构建、单元测试、Lint 和 API 37 模拟器 6 项播放交互回归；GitHub CI 在 Android 15 模拟器执行同一回归类。

**Debug 测试包，临时调试签名，不保证覆盖升级。** 不要为了绕过签名冲突直接卸载有数据的应用。厂商清理、强行停止、隔夜锁屏与耳机路由仍需真机验证；不宣称后台可靠性已全面通过。歌词仅支持本地 UTF-8 LRC，不包含自动语音转字幕。
