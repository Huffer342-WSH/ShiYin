# ShiYin v1.1.2

工程与交付流程更新，versionName 1.1.2 / versionCode 4。

- 项目自带 JDK 25 / SDK 37 构建容器，镜像由 GitHub Actions 构建并发布到本仓库关联的 GHCR 包；App CI 使用固定镜像 digest。
- 日常开发转到 dev；CI 仅由 PR → main、push main 或手动运行触发。普通 dev push 不跑 App CI，容器配方变更会触发镜像发布。
- Release 独立由版本 tag 触发。同一提交已有成功的 main CI 且产物未过期时直接复用 APK；否则重新执行完整检查后发布。
- APK 附带构建提交、工具链镜像、版本和 SHA-256 信息，发布时逐项核验。
- 清理 IDE/缓存/签名产物忽略规则，移除模板加法与包名测试，保留 38 项业务单元测试及播放交互回归。

仍为临时调试签名 Debug 测试包，不能保证跨构建覆盖升级。模拟器检查不代表 vivo 清后台、锁屏和隔夜闹钟可靠性已通过。
