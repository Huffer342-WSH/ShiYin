# ShiYin v1.1.0

本地音乐播放器与闹钟体验更新，APK versionName 1.1.0 / versionCode 2。

- 增加后台等待、App 主动移除最近任务卡片、开机解锁后恢复等待的逻辑，以及权限和厂商后台设置说明。
- 增加全屏响铃动画、停止控制和倒计时闹钟；倒计时支持点击重新开始。
- 底部 tab 栏上滑触发整页收起动画并进入后台，距离不足回弹。
- 播放页支持封面、真实音频波形和本地 LRC 歌词切换；美化进度条，拖动时同步显示目标时间。
- 修复倒计时切换触发全局加载样式闪烁、主题背景未跟随配色的问题。
- CI 拆分 build/test/release，模拟器测试和 Release 复用 build APK，并校验 SHA-256。

验证：本地构建、单元测试和 Lint 通过；API 37 模拟器播放交互回归 6 项通过，整页上滑动画专项复测通过。GitHub CI 另在 Android 15 模拟器执行播放交互回归。

**这是 Debug 测试包，使用临时调试签名。** 与之前 GitHub 包或本地开发包的签名可能不同，不能保证覆盖升级；不要为绕过签名冲突直接卸载有数据的应用。

vivo 的锁屏出声及全屏显示已有短时真机样本；系统上划清理与 App 主动移除卡片不同。强行停止、厂商清理和长期锁屏仍不能保证恢复，本版不宣称隔夜可靠性已通过。歌词仅支持本地 UTF-8 LRC，不包含自动语音转字幕。
