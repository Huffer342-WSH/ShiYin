# 时音 1.0.0 正式版

1.0.0 是时音首个正式版本，集中完善本地音乐管理、闹钟守护和首次运行配置。

## 主要更新

- 系统音乐库默认与自选目录同时扫描。目录页可独立开关系统来源和具体 MediaStore 目录，默认排除 `Recordings/` 及其子目录。
- 歌曲页支持按标题、文件名、文件路径、时长和创作者排序，并提供文件管理器式分类。
- 音频详细信息显示来源、位置、格式、大小和比特率。点击路径可复制，长按确认后可打开系统文件管理器。
- 首次启动显示可跳过的运行环境配置，逐项引导音乐、通知、精确闹钟、全屏响铃、守护包和 OriginOS 后台设置；设置页可查看完成度并继续配置。
- 主包内置同签名闹钟守护包。完成守护精确闹钟及 vivo 后台设置后，主应用被划掉或清除后台时仍可按预约冷启动响铃。
- 闹钟音频焦点首次被拒绝时不再中止播放，播放器会继续使用闹钟音频属性并异步重试焦点。

## 下载与升级

日常安装使用 `ShiYin-1.0.0-release.apk`，开发调试使用 `ShiYin-1.0.0-debug.apk`。0.2.0 Release 使用相同发布证书，可直接覆盖升级；Debug 与 Release 签名不同，二者不能相互覆盖。

守护包无需单独下载。主应用会从内置 APK 启动系统安装器，并校验两包签名。升级主应用后，可从“设置 → 闹钟守护包”覆盖安装新版守护组件。

## 验证范围

发布准备包含主应用与守护包的 JVM 单元测试、Debug Lint、Debug/Release 构建、发布脚本测试和 Android 模拟器首启检查。vivo OriginOS 5 的划卡冷唤醒已有历史真机样本；拔线长时间待机、设备重启恢复和主应用厂商开关的独立 A/B 仍未验证。
